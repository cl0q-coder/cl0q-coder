# cl0q — search the open web

cl0q is building an open index of the web: 43M+ domains known, ~1M pages crawled a day, working toward 100 million domains.

## Open source

- [crawler-node](https://github.com/cl0q-coder/crawler-node) — distributed web crawler (Go)
- [botid](https://github.com/cl0q-coder/botid) — bot identification library (Go)
- [robotstxt](https://github.com/cl0q-coder/robotstxt) — robots.txt parser (Go)
- [netguard](https://github.com/cl0q-coder/netguard) — network guard (Go)
